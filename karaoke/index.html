ใส่หูฟังตอนร้อง จะได้ไม่มีเสียงหอนและดีเลย์น้อยลง
ตั้งค่า YouTube API key (สำหรับการค้นหา)

สร้างได้ฟรีที่ Google Cloud Console → เปิดใช้ YouTube Data API v3 → สร้าง API key แล้วจำกัดให้ใช้ได้เฉพาะโดเมนเว็บของคุณ key จะเก็บไว้ในเบราว์เซอร์เครื่องนี้เท่านั้น

ต้นแบบนี้ตัดเสียงร้องในเครื่องด้วยการหักล้างเสียงกลางวง (เสียงร้องส่วนใหญ่อยู่ตรงกลาง) ใช้ได้ดีกับเพลงที่มิกซ์แบบปกติ อาจมีเสียงร้องหลงเหลือหรือเสียงก้องติดมาบ้าง เวอร์ชันจริงจะใช้ AI (Demucs) บนเซิร์ฟเวอร์ให้เสียงสะอาดกว่านี้
    คลังเพลงเก็บไว้ในเบราว์เซอร์ของเครื่องนี้ ถ้าจะใช้อีกเครื่อง หรือส่งให้เพื่อน ให้กด "แชร์คลังเพลง" แล้วส่งลิงก์ไปทาง LINE คนที่เปิดลิงก์จะได้เพลงชุดเดียวกันไปเล่นได้ทันที
    จับจังหวะเอง: วางเนื้อเพลงแล้วกดปุ่มนี้ เพลงจะเริ่มเล่นใหม่ตั้งแต่ต้น ให้แตะปุ่มใหญ่ทุกครั้งที่เริ่มร้องท่อนใหม่ แอปจะจำจังหวะไว้ รอบหน้าเนื้อเพลงจะวิ่งเอง

    เนื้อเพลงจาก LRCLIB เป็นข้อมูลที่ผู้ใช้ทั่วไปช่วยกันใส่ ไม่ได้มีลิขสิทธิ์ เหมาะใช้ส่วนตัว ไม่ควรเปิดให้ลูกค้าในร้านใช้
